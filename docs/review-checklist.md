# IAMポリシー・ロール レビューチェックリスト

## 1. 権限の過剰付与

- [ ] 許可するアクションは、設計目的を達成するために必要なものに限定されているか
- [ ] 不要な書き込み・削除権限が含まれていないか
- [ ] `s3:*` など、意図せず広範囲なアクションを許可していないか

## 2. 対象リソース

- [ ] `Resource` のARNは正しいか
- [ ] S3オブジェクトの対象範囲は設計どおりか
- [ ] ワイルドカード（`*`）の範囲は必要最小限か

## 3. 信頼ポリシー

- [ ] `Principal` は意図した主体になっているか
- [ ] `sts:AssumeRole` が適切に設定されているか
- [ ] 想定外の主体にロールを引き受ける許可を与えていないか

## 4. 構文・設定の整合性

- [ ] JSONまたはYAMLの構文検証に成功しているか
- [ ] `Effect`、`Action`、`Resource` の設定は設計書と一致しているか
- [ ] JSON版とYAML版の主要な設定内容は一致しているか

## 5. 検証・記録

- [ ] IAM Access Analyzerによるポリシー検証を実施したか
- [ ] 必要なアクションが想定したリソースに対して許可されることを確認したか
- [ ] 検証結果と修正内容を記録したか
